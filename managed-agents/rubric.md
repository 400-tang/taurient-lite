# 盘前简报评分标准

评分对象是仓库 `/workspace/taurient-lite` 里当天的 `briefs/<日期>.json`（日期为 `TZ=America/Los_Angeles date +%F`）以及 `/mnt/session/outputs/summary.md`。每一条独立打分，全部满足才算完成。

## 机械检查（跑命令，看结果）

1. **质量门通过。** `python3 check_brief.py <日期>` 的退出码为 0。只有 `summary.md` 明确写了板块热力取不到、原因是什么的情况下，才接受 `python3 check_brief.py <日期> --no-market` 退出码为 0。
2. **已经发布。** `git fetch` 之后 `git status -sb` 显示当前分支和远端同步（没有 ahead），`git log -1 --format=%s` 是 `简报 <日期>`；这个提交里包含 `briefs/<日期>.json`、`briefs/<日期>.md`、`site/index.html`，并且没有改动 `taurient_lite/`、`tests/`、`backend/`、`config.json` 下的任何文件。
3. **有总结。** `summary.md` 存在，写了当天的 `thesis`、各层条数、核查员改正了什么（没有改正也要写明），以及是否放弃了某个数据块。

## 内容判断（读简报）

4. **主线成立。** `thesis` 用一条因果线把当天的必读条目串起来，而不是把几条标题并列罗列。读完 `thesis` 能说出「今天市场在为什么定价」。
5. **分层合理。** 每条 `must-read` 都会影响一个大类资产的定价（利率、指数、美元、大宗、大市值公司）；没有明显应该是必读却放在 `noise`、或者只影响单个小公司却放在必读的条目。
6. **`why` 不复述新闻。** 抽查必读层和值得知道层的 `why`：每一条都说明了这件事**改变了什么判断**或**传导到哪里**，而不是把 `body` 换个说法再讲一遍。
7. **没有重复。** 同一个事件没有被拆成两条以上的条目；多家媒体的同一报道合并在一条的 `sources` 里。
8. **覆盖完整。** `config.json` 的 `scope` 列出的每个范围（宏观、科技与 AI、地缘与大宗）至少有一条条目，除非 `summary.md` 说明了当天确实没有相关新闻。
9. **没有建议，没有预测。** 全文没有任何买卖建议、目标价预测，或者「有望上涨」「预计将走高」这类对价格走向的判断；转述别人的观点时标明了是谁说的。
10. **异动措辞克制。** `momentum.candidates[*].note` 只描述价量上发生了什么，以及当天读到的新闻里恰好提到的内容；没有「今天没有相关报道」这类断言，也没有推荐语气。
